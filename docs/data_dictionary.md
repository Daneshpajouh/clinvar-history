# Data dictionary

Generated by `clinvar-history dictionary` from the DuckDB catalogue after `clinvar-history load`. Types are DuckDB names; PostgreSQL uses the equivalent types from the same migrations.

## source_release

One row per loaded source release. status 'rolled_back' keeps an audit row after clinvar-history unload. For ClinVar, release_date is the first day of the release month, not the day NCBI published the files. Rows in the build described in the README: 4.

| Column | Type | Nullable |
| --- | --- | --- |
| release_id | INTEGER | no |
| source | VARCHAR | no |
| label | VARCHAR | no |
| release_date | DATE | yes |
| status | VARCHAR | no |
| loaded_at | TIMESTAMP WITH TIME ZONE | yes |

## provenance

One row per input file: URL, size, SHA-256, fetch and load times, rows staged and loaded. Rows in the build described in the README: 30.

| Column | Type | Nullable |

| release_id | INTEGER | no |
| url | VARCHAR | no |
| local_path | VARCHAR | no |
| size_bytes | BIGINT | no |
| sha256 | VARCHAR | no |
| fetched_at | TIMESTAMP WITH TIME ZONE | no |
| loaded_at | TIMESTAMP WITH TIME ZONE | no |
| rows_staged | BIGINT | yes |
| rows_loaded | BIGINT | yes |
| terms | VARCHAR | yes |
